# Raw Dataset

This directory is intended for storing raw or unprocessed workload data used by the Intelligent Cloud Auto Scaling project.

## Data Sources

The current implementation uses simulated workload data generated by the reinforcement learning environment.

The simulated workload includes:

* CPU Utilization
* Request Count
* Instance Count

## Purpose

The raw workload values represent different cloud workload conditions and are used to evaluate how the Q-learning agent responds to changing resource demands.

## Current Status

No external raw dataset is currently stored in this directory. Workload values are generated programmatically during RL training and evaluation.

Future versions may include real or recorded cloud workload data for further experimentation.
